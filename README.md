# Android Message Feed

Учебное Android-приложение с лентой сообщений, профилем и настройками. Сообщения загружаются из JSONPlaceholder, сохраняются локально и доступны при временном отсутствии сети.

Проект разработан в рамках дисциплины «Мобильная разработка».

## О проекте

Приложение состоит из ленты сообщений, профиля пользователя и настроек. Переход между разделами выполняется через нижнюю навигацию. Обновление ленты работает вручную и в фоновом режиме.

## Основные возможности

- загрузка и отображение сообщений из REST API
- локальное хранение сообщений для работы без сети
- ручное обновление ленты
- добавление сообщений в избранное
- фоновая синхронизация при наличии интернета
- системное уведомление после фонового обновления
- редактирование имени и статуса в профиле
- переключение светлой и темной темы
- навигация между лентой, профилем и настройками

## Технологический стек

- Kotlin 2.0.21
- Android SDK и XML Layouts
- Android Architecture Components: ViewModel и LiveData
- Navigation Component
- ViewBinding
- Retrofit и OkHttp
- Room
- Kotlin Coroutines
- WorkManager
- Material Components

## Структура проекта

```text

├── java/com/mobile/lab1/
```

## Требования

- Android Studio
- JDK 17
- Android SDK 36
- устройство или эмулятор с Android 7.0 (API 24) или новее
- доступ к интернету для загрузки и фонового обновления сообщений

## Запуск проекта

```bash
git clone https://github.com/icecarti/android-message-feed.git
cd android-message-feed
```

1. Откройте проект в Android Studio.
2. Выполните `File → Sync Project with Gradle Files`.
3. Выберите эмулятор или подключенное устройство.
4. Запустите приложение через `Shift + F10`.
