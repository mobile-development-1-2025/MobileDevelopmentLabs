# Messenger
## Мобильная разработка 4 курс
Учебный Android-проект, 4 курс, дисциплина «Мобильная разработка».

## Описание
Приложение реализует многостраничный интерфейс с использованием навигационного графа, XML-разметки, сетевых запросов через Retrofit2 и локального кэширования данных через Room.
В приложении доступны три основных раздела:

- Лента новостей — отображение списка новостей, загрузка данных из сети и поиск по новостям.
- Чат — экран сообщений с локальным хранением и отображением переписки.
- Настройки — управление темой приложения и параметрами уведомлений.
Для получения данных из сети используется Retrofit2, а для локального кэширования новостей и сообщений — Room. Также в проекте используется WorkManager для фоновой работы, связанной с сообщениями и уведомлениями.

Основные возможности:
- навигация между экранами через nav_graph.xml;
- XML-разметка пользовательского интерфейса;
- нижняя навигация между разделами приложения;
- загрузка новостей через Retrofit2;
- кэширование данных в локальной базе Room;
- поиск по ленте новостей;
- экран чата;
- настройки темы приложения;
- поддержка уведомлений;
- использование ViewBinding для работы с UI-компонентами.

Технологический стэк:
- Kotlin
- Android SDK
- XML Layouts
- Android Navigation Component
- ViewBinding
- Retrofit2
- Gson Converter
- Room
- Kotlin Coroutines
- WorkManager
- Material Components
- Glide

## Требования
Перед запуском необходимо установить:
- Android Studio;
- JDK, совместимый с используемой версией Gradle;
- Android SDK;
- эмулятор Android или физическое устройство;
- подключение к интернету для загрузки новостей.

Минимальная поддерживаемая версия Android: **24**  
Целевая версия SDK: **34**

## Инструкция по запуску в Android Studio
### 1. Клонировать репозиторий
```shell
git clone https://github.com/repeatuntil/mobile_dev_messenger.git
```

### 2. Установить зависимости
```shell
File → Sync Project with Gradle Files
```

### 3. Запустить приложение
```shell
Shift + F10
```
